# HRMS
Offline multi-profile Self Attendance &amp; Payroll Management System with attendance tracking, salary calculation, PF/ESIC deductions, salary slips, backup &amp; restore, MPIN security, and PWA support.


## Production build
- PWA starts at Login.
- Login/MPIN guard remains enabled for protected HRMS pages.
- Canonical Attendance and Payroll routes are cached for offline use.
- Development `.bak` files removed from the distribution.
- Dashboard includes Account and Lock shortcuts.
